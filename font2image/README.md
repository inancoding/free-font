# font2image

本地**字体预览图生成工具**：把字体文件（.ttf / .otf / .woff / .woff2 / .ttc）渲染成静态预览图片与网页封面图，用于字体网站展示。核心渲染流程离线运行，不上传字体文件。选择 Lorem Picsum 背景图时需联网获取图片。

## 为什么需要它

中文字体通常 5MB 以上，个人开发者搭建字体网站时，在线 `@font-face` 加载成本高、体验差。font2image 把「字体预览」从在线渲染改为**离线预生成图片**：本地把字体渲染成样张图，网站只展示静态图片。

---

## 功能特性

- **语种自动判定**：基于 cmap 探测四类语种能力——简体 / 繁体 / 简繁双全 / 英文，支持手动改选字符类型（简体汉字 / 繁体汉字 / 英文字母 / 数字）
- **字符集覆盖探测**：GB2312-80、GBK、Big5 三组中文编码标准的抽样覆盖率（各 300 字探测），显示字形总数
- **诗词样张库**：内置多首朗朗上口的经典诗词（简体、繁体双版本），也支持在 `poems.json` 中人工新增
- **单图排版**：所选字符类型合并为一张图；诗词每两句一行，字母在 M 后换行，全部居中
- **网页封面图**：每个字体同时生成 3:1 封面（仅字体名称，居中）
- **多格式输出**：PNG（默认）/ WebP / JPG，双尺寸（96 / 192px 高度）
- **背景图片**：一键从 [Lorem Picsum](https://picsum.photos) 获取随机风景图作为预览图与封面图底图（同一张图，尺寸自动适配），可调节黑色遮罩透明度（默认 55%）；CLI 也支持本地文件路径
- **缺字过滤**：自动剔除字体不包含的字符，杜绝「豆腐块」
- **批量 + 增量**：目录批量生成；字体哈希 + 配置哈希未变化时自动跳过
- **UI 批量模式**：一次拖入多个字体，逐字体自动判定，全部产物打包为单个 zip 下载
- **manifest.json**：输出附带结构化清单，供网站直接消费
- **本地可视化 UI**：拖入字体 → 选诗词 → 实时预览 → 一键下载；响应式布局（≥960px 左右分栏，<960px 上下堆叠）；通知消息以右侧吐司弹窗呈现，5 秒自动消失；支持文字颜色选择与 Lorem Picsum 随机风景背景
- **ttc 集合字体**：宋体、微软雅黑等 `.ttc` 自动拆包（取集合内第一个字体），解析失败给出具体原因

## 环境要求

- Node.js ≥ 22（本机开发环境为 Node 22+ / 24）
- pnpm（`npm install -g pnpm`）
- 本机已安装 Edge 或 Chrome（CLI 无头渲染复用本机浏览器，无需下载 Chromium）

## 安装

```bash
cd font2image
pnpm install
```

## 快速开始

### 方式一：本地 UI（推荐，交互式）

```bash
pnpm ui
# 打开 http://localhost:5173
```

流程：拖入/选择字体 → 查看元数据与语种判定 → 选择诗词 / 编辑样张文本 → 实时预览 → 选择格式与尺寸 → 「生成并下载」。

- **响应式布局**：页面宽度 ≥960px 时采用左右分栏（左侧控制面板可滚动，右侧预览区吸顶固定），<960px 时自动切换为上下堆叠。
- **单字体精调**：拖入一个文件，可手动改选字符类型、编辑样张文本、选择文字颜色、一键获取 Lorem Picsum 随机风景背景，实时预览。
- **批量模式**：一次拖入/选择多个文件，逐字体自动判定语种，失败逐条列出原因不中断，「生成并下载 zip」把所有产物（命名与 CLI 一致）打包为 `font2image-batch.zip` 一次性下载。批量模式沿用页面上的诗词与输出选项设置，不支持逐字体微调（需要时用单字体模式）。
- **交互细节**：语种覆盖率详情悬停在判定结果标签上弹出；操作反馈以右侧吐司弹窗呈现，5 秒自动消失。

> 注意：本地 UI 不支持 woff2（浏览器无法解包），遇到时请先用 CLI 转换。

### 方式二：CLI（批量）

```bash
# 单文件
pnpm gen "D:\字体\SourceHanSerifCN-Regular.otf"

# 批量（递归扫描目录）
pnpm gen --in "D:\免费商用字体" --out output

# 常用参数组合
pnpm gen --in "D:\免费商用字体" --format webp --scripts hans,letter,digit --sizes 96,192
```

所有产物默认输出到 `output/` 目录。

## CLI 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `[files...]` | 一个或多个字体文件（与 `--in` 二选一） | — |
| `--in <dir>` | 字体目录，按配置决定是否递归扫描 | — |
| `--out <dir>` | 输出目录 | `output` |
| `--format <fmt>` | 输出格式：`png` / `webp` / `jpg` | `png` |
| `--text <text>` | 强制指定完整样张文本（优先级最高，覆盖诗词组合） | — |
| `--poem <id>` | 指定诗词（见 `poems.json` 中的 `id`） | 配置默认（第一首） |
| `--scripts <list>` | 手动指定字符类型：`hans,hant,letter,digit` 任意组合 | 按自动判定 |
| `--sizes <list>` | 高度列表，逗号分隔，如 `96,192` | `96,192` |
| `--quality <n>` | webp/jpg 质量 1-100 | `90` |
| `--background <c>` | 背景色（`#ffffff` 或 `transparent`） | `#ffffff` |
| `--color <c>` | 文字颜色 | `#000000` |
| `--config <path>` | 配置文件路径 | `font2image.config.json` |
| `--force` | 忽略增量缓存，强制重新生成 | 关 |
| `--bg-image <path>` | 背景图片：本地路径（jpg/png/webp）或 `picsum:<seed>`（Lorem Picsum 风景图，seed 留空则随机） | 无 |
| `--bg-opacity <n>` | 背景图遮罩透明度 0-1（0=完全裸露背景图，1=纯色遮挡） | `0.55` |

示例：

```bash
# 繁体字体 + 数字，指定《春晓》，输出 webp
pnpm gen "MOE-StandardSong.ttf" --scripts hant,digit --poem chun-xiao --format webp
```

## 配置文件 `font2image.config.json`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `sizes` | number[] | `[96, 192]` | 预览图高度档位（宽度自适应） |
| `format` | string | `"png"` | 输出格式 |
| `quality` | number | `90` | webp/jpg 质量 |
| `threshold` | number | `0.6` | 语种判定阈值：覆盖率 ≥ 60% 视为具备该字库 |
| `background` | string | `"#ffffff"` | 背景色，可为 `transparent` |
| `color` | string | `"#000000"` | 文字颜色 |
| `maxFileSizeMB` | number | `30` | 字体文件大小上限，超过则跳过 |
| `maxImageWidth` | number | `2400` | 单行最大宽度，超出自动换行 |
| `coverWidth` | number | `1200` | 封面图宽度（高度 = 宽度 ÷ 3） |
| `recursive` | boolean | `true` | 批量扫描是否递归子目录 |
| `showMissing` | boolean | `false` | 为 `true` 时保留缺字（便于排查），默认剔除 |
| `poem` | string | `"jing-ye-si"` | 默认诗词 id，`""` 表示诗词库第一首 |
| `bgImage` | string | `""` | 背景图片：本地路径或 `picsum:<seed>`（Lorem Picsum 风景图），`""` 表示不使用背景图 |
| `bgOpacity` | number | `0.55` | 背景图遮罩透明度（0=完全裸露背景图，1=纯色遮挡） |

## 诗词样张库 `poems.json`

诗词库位于项目根目录 `poems.json`，UI 与 CLI 共用，**可直接编辑、人工新增**，无需改代码。

### 格式

```json
[
  {
    "id": "jing-ye-si",
    "title": "静夜思",
    "author": "李白",
    "hans": "床前明月光，疑是地上霜。举头望明月，低头思故乡。",
    "hant": "床前明月光，疑是地上霜。舉頭望明月，低頭思故鄉。"
  }
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识（英文短横线命名），用于 `--poem` 与配置 |
| `title` | 是 | 诗题（UI 下拉显示） |
| `author` | 否 | 作者 |
| `hans` | 是 | 简体版本全文（含标点） |
| `hant` | 是 | 繁体版本全文（含标点） |

### 新增诗词的步骤

1. 打开 `poems.json`，在数组中追加一个对象；
2. **必须同时提供简体、繁体两个版本**（工具不做运行时简繁转换，逐字人工对照最可靠）；
3. `id` 不能与已有诗词重复；保存后重启 `pnpm ui`（Vite 会自动热更新）或直接运行 CLI 即生效。

### 排版规则（自动应用）

- 诗词按标点（，。！？等）断句，**每两句排为一行**，如「床前明月光，疑是地上霜。」一行；
- 英文字母固定四行：`ABCDEFGHIJKLM` / `NOPQRSTUVWXYZ` / `abcdefghijklm` / `nopqrstuvwxyz`（在 M 后换行）；
- 数字固定一行 `0123456789`；
- **所有文本行水平居中**。

## 输出产物与命名

所有产物统一保存在 `output/`（或 `--out` 指定的单一目录），不产生衍生子目录：

| 文件 | 命名 | 说明 |
|---|---|---|
| 预览图 | `<字体文件原名>-<高度>.<扩展名>` | 如 `SourceHanSerifCN-Regular-96.png`；保留原文件名大小写，无语种/风格前后缀 |
| 封面图 | `<字体文件原名>-cover.<扩展名>` | 宽高比 3:1，仅字体名称（家族名，中文优先）一行，居中 |
| 清单 | `manifest.json` | 每个字体的元数据、判定结果、覆盖率、字符集覆盖（GB2312/GBK/Big5）、字形总数与所有图片信息 |

批量时若不同目录出现同名字体文件，自动追加 `-2`、`-3` 序号避免覆盖。

### 单图内容组成

按所选字符类型合并为一张图，顺序为：

1. 简体诗词（两句一行）——勾选「简体汉字」时
2. 繁体诗词（两句一行）——勾选「繁体汉字」时（简繁双全时两段都有）
3. 英文字母四行——勾选「英文字母」时
4. 数字一行——勾选「数字」时

### 背景图片渲染

UI 点击「随机风景」按钮，从 [Lorem Picsum](https://picsum.photos) 获取一张风景图（尺寸取封面图宽高 1200×400），预览图与封面图自动使用同一张图；CLI 通过 `--bg-image picsum:<seed>` 指定同一张 Picsum 风景图，也可使用本地文件路径。渲染流程为：

1. 背景图片按 **cover 模式**缩放至铺满画布（保持宽高比，居中裁切），自动适配预览图与封面图各自的宽高；
2. 叠加一层**黑色半透明遮罩**（透明度由 `bgOpacity` 控制，默认 55%），用于提升文字可读性；
3. 在遮罩上方绘制文字内容。

遮罩透明度为 0 时背景图完全裸露，为 1 时等效纯色背景。预览图与封面图始终使用同一张背景图片。

### 增量生成

以「字体文件哈希 + 配置哈希」判定：两者均未变化且产物齐全时跳过（报告中显示 `[→] 增量跳过`）。想强制重跑加 `--force`。

## 语种判定规则

基于内置的简体特有字表与繁体特有字表（各 465 个高频字，成对设计）采样探测覆盖率：

| 判定结果 | 条件 |
|---|---|
| 简繁双全 | 简体、繁体特有字覆盖率均 ≥ 阈值（默认 60%） |
| 简体 | 简体覆盖率高、繁体低于阈值 |
| 繁体 | 繁体覆盖率高、简体低于阈值 |
| 英文 | 汉字覆盖率低、拉丁字母覆盖率高 |

判定结果决定默认勾选的字符类型，UI 中可用复选框手动改选（至少保留一项）；CLI 用 `--scripts` 等价覆盖。日文、韩文未实现，判定层采用字符集表驱动设计，预留扩展位。

## 技术架构

```
src/
├── core/        与平台无关的核心逻辑（UI / CLI 共用）
│   ├── charsets.ts  简繁特有字对照表、字符集表驱动设计
│   ├── charset-probes.ts  GB2312/GBK/Big5 探测样本字面量
│   ├── charset.ts   字符集覆盖抽样计算
│   ├── detect.ts    覆盖率计算与四类语种判定
│   ├── poems.ts     诗词库类型、校验、两句一行断句
│   ├── samples.ts   样张组合（诗词 + 字母 + 数字）
│   ├── filter.ts    缺字过滤（基于 cmap）
│   ├── naming.ts    输出命名规则
│   ├── config.ts    默认配置与合并
│   └── types.ts     公共类型
├── parse/       字体解析
│   ├── font.ts      opentype.js 封装（元数据、cmap 查询、字符集探测、签名嗅探）
│   ├── ttc.ts       ttc 集合拆包（取第一个字体）
│   ├── sfnt.ts      SFNT 容器重建（woff2 / ttc 共用）
│   └── woff2.ts     woff2 → SFNT 解包（Node zlib brotli）
├── render/
│   └── draw.ts      自包含绘制函数：样张（居中排版）与 3:1 封面
├── cli/         命令行批量管线
│   ├── index.ts     入口与参数解析
│   ├── pipeline.ts  单字体处理管线（校验→解析→判定→渲染→落盘）
│   ├── browser.ts   Playwright 无头渲染会话（复用本机 Edge/Chrome）
│   ├── poems-io.ts  poems.json 加载
│   ├── incremental.ts  文件/配置哈希
│   ├── manifest.ts  manifest.json 读写
│   └── scan.ts      目录扫描
└── ui/          本地网页界面（Vite + React）
    ├── App.tsx      单页应用（单字体精调 + 批量模式）
    ├── zip.ts       零依赖 zip 打包（批量模式下载）
    └── styles.css   现代视觉样式
```

关键设计：

- **两端一致渲染**：`draw.ts` 的绘制函数完全自包含，UI 直接 import，CLI 通过 `toString()` 注入 Playwright 页面执行，保证两种模式输出像素级一致；
- **浏览器级保真**：渲染走真实浏览器 Canvas + FontFace，字距与 OpenType 特性与网页展示一致；
- **零下载浏览器**：playwright-core 直接拉起本机 Edge/Chrome，不需要下载 Chromium。

## 已知限制

- **woff2**：解码器已实现（brotli 解压 + SFNT 重组），但仅支持「未变换表」的常规容器；遇到带变换的 glyf/loca 会明确报错提示先转成 ttf/otf。本地 UI 不支持 woff2。
- **ttc 集合**：拆包时仅取集合内的**第一个**字体；需要集合中其他字体时请先用字体工具拆分。
- **日文 / 韩文**：未实现判定与样张，仅预留字符集表驱动的扩展位。
- **纯位图字体**：能解析元数据，但浏览器字体引擎无法渲染，会给出明确提示。
- **jpg**：有损压缩，文字边缘质量较低，建议使用 png 或 webp。

## 常见问题

**Q：CLI 报「未找到可用的本机浏览器」？**
A：确认已安装 Edge 或 Chrome。工具按 `msedge` → `chrome` 顺序尝试。

**Q：为什么改完 `poems.json` UI 没变化？**
A：Vite 通常会自动热更新；若没有，重启 `pnpm ui`。

**Q：同一个字体第二次运行没有重新生成？**
A：这是增量生成在工作。字体与配置都没变化时会跳过，用 `--force` 强制重跑。

**Q：UI 里上传 woff2 被拒绝？**
A：浏览器端无法解包 brotli，请先用 CLI：`pnpm gen 字体.woff2`（CLI 会解包后正常生成）。

**Q：之前提示「字体解析失败：Invalid font data in ArrayBuffer」？**
A：这是旧版底层库的笼统报错，最常见原因是 `.ttc` 集合字体（宋体、微软雅黑等）。现已支持 ttc 拆包，并对无法识别的格式、浏览器无法渲染的字体给出具体原因。
